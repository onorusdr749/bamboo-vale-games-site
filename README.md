# Bamboo Vale Games

The public static website for Bamboo Vale Games, Matt's personal game-development and publishing brand. It is designed to provide a welcoming home for present and future games, including Cookie Cub.

## Local use

No build step or dependencies are required. Open `index.html` in a browser, or serve this folder with any simple static-file server when testing route behavior.

The site is intended to be served directly from the repository root on GitHub Pages and later connected to the `bamboovalegames.com` custom domain. A `CNAME` file is intentionally not included yet.

## Structure

```text
index.html                 Bamboo Vale Games home page
styles.css                 Shared responsive styles
cookie-cub/index.html      Cookie Cub game page
cookie-cub/privacy/        Privacy Policy placeholder route
cookie-cub/support/        Support placeholder route
```
